# 문제 검색·선택 화면

- 기존 색상과 글꼴은 `web/styles.css`의 `--brand`, `--surface`, `--line`, `--focus` 토큰을 사용한다.
- 상단 검색 탭과 검색어·조건 칩, 왼쪽 240~280px 분류 패널, 중앙 원본 이미지 카드, 하단 선택·담기 막대를 둔다.
- 단원·출처·나만의 분류의 실제 저장값만 표시한다. 같은 분류는 OR, 서로 다른 분류는 AND이다. 빈 값은 미분류로 표시한다.
- 카드는 가용 폭에 따라 최소 약 260px의 3/2/1열로 흐르게 한다. 원본 비율을 유지하고 긴 문제는 전체보기를 제공한다.
- 번호와 출처명은 기존 값을 보여준다. 새 내부 출처 코드는 서버에서만 관리하고 HTML·응답·브라우저 저장소·출력에 싣지 않는다.
- 문항 선택과 그림 재생성 선택은 별개이며, 선택과 이미 담긴 상태도 구분한다. 탭마다 검색·조건·정렬·페이지·스크롤을 기억한다.
- 하단 막대가 카드와 페이지 이동을 가리지 않도록 공간을 둔다. 체크 표시·문자 설명·키보드 초점으로 색상 외 상태를 알린다.

2026-09-24 복사 데이터 기준: 9개 프로젝트, 1,496문항, 5개 문제지. 근거 파일은 `.omo/evidence/search-ui-provenance-build/task-1-baseline.json`이다. 운영 작업공간은 사용 중이어서 복사 후 일부 문항이 계속 수정되었다. 구현·검사는 복사본의 기록된 해시에 묶는다.

## 저장된 문항의 문제·해설 함께 보기

- 기존 `--brand`, `--surface`, `--line`, `--focus`와 한글 글꼴을 사용한다. 읽기 카드 두 개는 같은 시각적 위계와 폭을 갖는다.
- 본문 가용 폭 900px 이상에서 문제 왼쪽·해설 오른쪽, 그보다 좁으면 문제 위·해설 아래에 둔다. 넓은 화면은 패널별 스크롤, 좁은 화면은 문서 스크롤을 사용한다.
- 각 카드의 원본/읽기 선택은 독립적이며 `aria-pressed`로 표시한다. 원본 이미지 비율과 수식의 내부 가로 스크롤을 보존한다. 없는 자료는 빈 상태로 알려준다.
- 두 카드는 읽기 영역이고 기존 탭과 편집 DOM은 하나만 둔다. 편집 버튼은 해당 탭의 접이식 작업대를 열며 미저장 초안을 유지한다. 해설 원본 도구와 정답은 해설 쪽에서 찾을 수 있게 한다.
- 태그와 프로젝트 요약은 한 줄 안내와 펼치기 영역으로 배치한다. 저장 상태와 현재 편집 대상은 색상 외 텍스트로 표시한다. 검색 화면의 스타일과 상태는 유지한다.
