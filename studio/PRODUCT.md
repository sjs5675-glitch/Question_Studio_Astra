# Astra product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
The current user prepares Korean science/physics questions and worksheets. The redesign covers the entire app, not a preferred subset (confirmed 2026-09-26).

## Product Purpose
Import question and solution sources, inspect and edit saved questions, search a bank, assemble ordered worksheets, edit documents and export usable HWPX/PDF.

## Operating Context
Windows local application, Korean text, mathematical equations and original figures. Existing project and question records are valuable user content.

## Capabilities and Constraints
Cover import, exam region editing, saved question/solution reading and editing, question bank, worksheet assembly, analysis examples, and document editing. Preserve current APIs, IDs, drafts, data, equations and export semantics. HWPX is always two columns; assembled question numbers are continuous from one. No column selector. Use the existing vanilla HTML/CSS/JS and document bundle.

## Product Principles
Make all existing actions findable. Group controls by task. Let question and document content lead. Keep destructive actions distinct. Preserve original records.
