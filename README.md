# Question Studio Astra

문제 이미지 분할, 전사, 검토, 문제은행 관리, 문서 편집과 PDF/HWPX 출력용 로컬 앱의 소스 코드입니다.

저장된 문제, 작업공간, 실행 기록, 학습 데이터베이스와 개인 설정은 이 공개 저장소에 포함하지 않습니다. 새 설치에는 Python/Node 의존성 및 로컬 실행 환경 설정이 필요합니다. 실행 설정과 의존성은 `pyproject.toml`, `studio/requirements.txt`, `studio/web/package.json`, `crop/web/package.json`을 참고하세요.

공개 소스는 2026-09-24 현재 로컬 작업 트리의 스냅샷입니다. 로컬 저장 데이터와 Git 이력은 별도로 보관됩니다.
